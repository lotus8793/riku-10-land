# りくのぼうけん

## モード

| タブ | 内容 | ゲージ初期値 |
|------|------|--------------|
| あわせて10 | 10の補数ペア | ミッションのみ |
| 10+X | 10といくつ | ミッションのみ |
| かみなりジム | フラッシュ暗算。10マス（5×2）に1〜10個のブロックを一瞬だけ見せて個数を答える | ミッションのみ |
| たしざんジム | 答えが10以下の足し算（45問）。答え10の次は片方を1減らし、答えが9になる比較問題 | 全ゲージ |
| もぎダンジョン | 左右の10マスからブロックをドラッグして10をつくる | ミッションのみ |
| ほのおのダンジョン | くり上がりのさくらんぼ計算。赤四角が10マスへ飛んで10が完成 | 全ゲージ |
| ひきざんジム | 10以内の引き算（45問）。✕で消えるアニメーション | 全ゲージ |
| こおりのダンジョン | くり下がりの引き算（13−8 など） | 全ゲージ |
| とうし | おかねの勉強。100円単位でとうし／うる、もとでとの比較グラフ | — |
| ずかん / カレンダー / きろく / 統計 / 設定 | 図鑑・記録・保護者向け | — |

ゲージは3本: **ポケモンゲット**・**きょうのミッション**・**コインゲージ**。
「全ゲージ」= 3本すべてに進む。「ミッションのみ」= きょうのミッションだけに入る。

**どのタブがどのゲージに進むかは、設定タブの「ゲージに入れるタブ」でタブごとにチェックを切り替えられる**（上の表は初期値）。
ミッションはタブごとの必要問題数（0で今日は必須から外す）で制御する。

## ポケモンシステム

- 「じかんあり」の正解10問ごとにゲットチャンス（設定で「ポケモン」にチェックしたタブの正解を数える。初期はジム・ダンジョンの4タブ）
- ポケモンにチェックのあるタブは、間違えると進みが1つ戻る（ミッションの進捗も1つ戻る）
- ボール演出: 揺れる → 金色=ゲット（80%）/ はじけて逃げられる（20%）
- 色違い10%。演出中はタイマー停止、「つぎへ」で再開
- きょうのミッション: **タブごとに必要問題数を設定**（初期値: たしざん/かみなり各20、あわせて10/10+X/もぎ/ほのお各10、ひきざん/こおり各5）。全タブ埋めるとボーナス1匹（確定）。設定タブで **0にするとそのタブは今日の必須から外れる**
- 貯金（さいふ）は設定タブの「貯金のせいさん」で **100円単位で任意に減らせる**（−100/−500/−1000のボタン、または金額を直接入力）。残高不足・100円未満の端数は弾かれる。全額クリアは「さいふを0円にする」
- 図鑑: 60種。重複は×Nバッジ、色違い持ちは✨。所持数順ソート、未ゲットは？
- 「ぜんぶにがす」で図鑑と累計をリセット
- じかんなしモードは練習用（ゲット対象外）

## かみなりジム（フラッシュ）

「7 = 上の段に5個、下の段の左から2個」という**5のかたまりでの見え方**を体に入れるためのモード。

- 「よ〜い…」→ ブロックが1.5秒（設定で0.2〜10秒）だけ光って消える → 1〜10のカードで答える
- 答え合わせで**上の段5個を緑・下の段のあまりを赤**に塗り分け、「うえのだん 5こ と したのだん 2こ で 7」と表示
- 3・4・8・9 は2行目に「**10より 1こ すくないだけ！ あと1こで 10**」を追加し、足りないマスを点線で光らせる（きりのいい数からの引き算でも見えるように）
- 数えるのが間に合わないときは「もういちど みる」で2回まで見直せる
- からのマスもうっすら表示。5と5の境目に破線を入れて2段構造を見せる
- 出る数は **5〜10が約95%**（上の段が5でうまって、下の段があといくつ、の練習）。1〜4は約20問に1問のごくまれ
- そのうえで苦手優先出題が効くので、間違えた数・時間がかかった数がよく出る
- じかんあり: ブロックを見ているあいだタイマーは止まり、隠れてから動きだす
- 初期はミッションのみカウント（20問）。設定でポケモン・コインゲージにも入れられる

設定タブで「表示時間（0.2〜10秒）」「最大の数（3〜10）」を変更できる。
初期値は1.5秒。うまくいかないときは3秒くらいに伸ばし、慣れたら短くしていくと数えグセが抜けやすい。
10個が多すぎるときは「最大の数」を6や7に下げる。

## とうし（おかねの勉強）

さいふ（貯金）のおかねを「とうし」に移して、時間の経過で何が起きるかを見るタブ。
※「ぎんこう」も作ったが、増えないなら財布と同じなので廃止した。

- **さいふ**: 問題を解いて貯まるおかね。ここから100円単位でとうしする
- **もとで**: とうしに入れた元本の合計
- **とうし（いま）**: 1日ごとに変動する。初期は **1日 +10% ± 15%（= −5%〜+25%）**。もとでとの差を「もとでより +◯円 / −◯円」で表示
- **ぜんぶ うる** で全額をさいふに戻し、いくら増えた／減ったかを教えてくれる
- グラフ: **もとで**（青・水平）と **とうしのいまのねだん**（オレンジ）の折れ線。2本のひらきがそのまま損益。直近30日、ライブラリなしのSVG
- 一部だけ売ると、もとでも同じ割合で減る（損益の計算を合わせるため）

値動きは**実日数**でつく。前に開いた日から今日までをまとめて計算するので、アプリを開いていなくても進む（久しぶりに開いたときは直近60日ぶんだけ計算）。

設定タブで「とうしの金利」「とうしのブレはば」を変更できる。
ブレはばを0にすると必ず増える。金利をマイナスにすれば「減る」体験もできる。

### データの持ち方

- さいふは `riku10v2-wallet-yen`（円）。旧 `riku10v2-coins`（100円が何枚か）からは自動で ×100 して引き継ぐ
- とうしと日ごとの記録は `riku10v2-finance`（`history` は `{ d: 日付, p: もとで, v: いまのねだん }`）
- 旧「ぎんこう」に残高があった場合は、起動時にさいふへ自動で戻す

## 演出

- 正解で紙吹雪＋ほめことば6種ランダム＋コンボ表示（🔥Nれんぞく）
- 正解音はアルペジオ。コンボ5ごとに1音ずつ豪華に（最大7音）
- もぎダンジョンは左右の間隔を広げ、ブロック1つ1つの枠を左＝黒・右＝白に分けて「別のあつまり」に見せている（移動すると枠の色も引っこし先に変わる。中の色は生まれたがわのまま）

## 注意

- ポケモン画像はPokéAPI（公式アートワーク）から取得。初回はオンライン必須、以降はキャッシュ
- ポケモンは任天堂の著作物のため**ネット公開・配布はしないこと**（家庭内利用のみ）

## 試し方

`index.html` をブラウザで開く。PWAはObsidianSyncルートで:

```sh
python3 -m http.server 8097
```

→ `http://localhost:8097/Projects/riku-10-land/index.html`

iPhoneは同じWi-FiでMacのIPを使い、Safari共有→「ホーム画面に追加」（モンスターボールのアイコンになる）。
