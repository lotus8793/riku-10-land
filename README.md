# りくのぼうけん

## モード

| タブ | 内容 | ゲージ初期値 |
|------|------|--------------|
| あわせて10 | 10の補数ペア | ミッションのみ |
| 10+X | 10といくつ | ミッションのみ |
| かみなりジム | フラッシュ暗算。10マス（5×2）に1〜10個のブロックを一瞬だけ見せて個数を答える | ミッションのみ |
| たしざんジム | 答えが10以下の足し算（45問）。左右のブロックが下の10マスへ合流。答え10の次は片方を1減らし、答えが9になる比較問題 | 全ゲージ |
| もぎダンジョン | 左右の10マスからブロックをドラッグして10をつくる | ミッションのみ |
| ほのおのダンジョン | くり上がりのさくらんぼ計算。「小＋大」「大＋小」を同じ基礎頻度で出し、通常は小さい数の後ろ側から大きい数へ赤四角が飛ぶ。困ったときは同じ式を「もぎで考える」補助盤面で実際に動かせる | 全ゲージ |
| ひきざんジム | 10以内の引き算（45問）。引く数だけ好きなブロックを選んで消してから答える | 全ゲージ |
| こおりのダンジョン | くり下がりの引き算（13−8 など） | 全ゲージ |
| ゲームじかんやさん | さいふの500円をゲーム時間1時間と交換。購入時にレジ音が鳴る | — |
| ずかん / カレンダー / きろく / 統計 / レポート / 設定 | 図鑑・記録・保護者向け | — |

ゲージは3本: **ポケモンゲット**・**きょうのミッション**・**コインゲージ**。
「全ゲージ」= 3本すべてに進む。「ミッションのみ」= きょうのミッションだけに入る。

**どのタブがどのゲージに進むかは、設定タブの「ゲージに入れるタブ」でタブごとにチェックを切り替えられる**（上の表は初期値）。
ミッションはタブごとの必要問題数（0で今日は必須から外す）で制御する。
時間・ブロック・解説・解説待ちの切り替えは、子どもが問題画面から変更できないよう**設定タブ（保護者向け）だけ**に置いている。解説待ちは初期値ONで、解説アニメーションが完了するまで「つぎへ」を表示しない。OFFでは従来どおり途中で進める。画面上部には、さいふ・購入済みゲーム時間・現在のミッション連続クリア日数を表示する。
設定タブ全体は4桁の保護者用暗証番号でロックできる。初回に暗証番号を2回入力して設定し、設定タブを離れると自動で再ロックする。3回間違えると30秒間入力を停止する。暗証番号と8桁の復旧コードは平文では保存せず、端末内にはハッシュだけを保存する。解除後の設定画面では、暗証番号の変更・ロック解除・復旧コードの再発行ができる。
ほのおのダンジョンの「左→右固定」は設定タブで切り替えられる。OFF（初期値）は式の左右に関係なく小さい数から大きい数へ、ONは式の左から右へ移す。どちらも移動元の後ろ側からブロックを移す。
ほのおの出題中に、選択肢の下にある小さな「わからない → もぎで考える」を開くと、その問題と同じ左右の数を10マスで表示する。ブロックを移して片側を10にすると、残りを「10 + のこり」のヒントで示す。もぎヒントを一度でも開いた問題は練習扱いになり、正解・不正解の成績、時間ありの得点、累計正解、コイン、ポケモン、ミッションのすべてに数えない。さらに、その問題で初めてヒントを開いたとき、未完了のほのおミッション進捗があれば1問戻す（すでに今日の全ミッションをクリア済みなら戻さない）。

## ポケモンシステム

- 「じかんあり」の正解10問ごとにゲットチャンス（設定で「ポケモン」にチェックしたタブの正解を数える。初期はジム・ダンジョンの4タブ）
- ポケモンにチェックのあるタブは、間違えると進みが1つ戻る（ミッションの進捗も1つ戻る）
- ボール演出: 揺れる → 金色=ゲット（80%）/ はじけて逃げられる（20%）
- 色違い10%。演出中はタイマー停止、「つぎへ」で再開
- きょうのミッション: **タブごとに必要問題数を設定**（初期値: たしざん/かみなり各20、あわせて10/10+X/もぎ/ほのお各10、ひきざん/こおり各5）。全タブ埋めるとボーナス1匹（確定）。設定タブで **0にするとそのタブは今日の必須から外れる**
- 貯金（さいふ）は設定タブの「貯金のせいさん」で、**渡した金額を1円以上の整数で直接入力して任意に減らせる**。100円刻みの制限やプリセットはない。残高不足は弾かれる。全額クリアは「さいふを0円にする」
- 図鑑: 150種。重複は×Nバッジ、色違い持ちは✨。所持数順ソート、未ゲットは？
- 「ぜんぶにがす」で図鑑と累計をリセット
- じかんなしモードは練習用（ゲット対象外）

## 統計・レポート

- 統計は月ごとのカレンダー形式。各日に正解・不正解を合わせた「解いた問題数」を表示する
- 統計は保護者向けとして漢字表記にする。日付を選ぶと、8カテゴリ別にその日の「間違えた問題」と「20秒以上かかった問題」を理由ラベル付きで表示する
- 日別表示の下には、更新前から蓄積している全期間の問題別成績を使い、誤答がある問題または回答時間が20秒以上の問題を苦手度順に各カテゴリ5問まで表示する
- 問題別の日別内訳は、この仕様への更新後に解いた問題から保存する。更新前の履歴も日別合計数は引き続き表示する
- 1週間レポートは子供向けの表現を維持し、「できるようになった問題」は表示しない
- 「つぎ がんばる もんだい」は直近7日間に間違えた問題、または20秒以上かかった問題だけを表示する（正答率は表示しない）

## かみなりジム（フラッシュ）

「7 = 上の段に5個、下の段の左から2個」という**5のかたまりでの見え方**を体に入れるためのモード。

- 「よ〜い…」→ ブロックが1.5秒（設定で0.2〜10秒）だけ光って消える → 1〜10のカードで答える
- 答え合わせで**上の段5個を緑・下の段のあまりを赤**に塗り分け、「うえのだん 5こ と したのだん 2こ で 7」と表示
- 3・4・8・9 は2行目に「**10より 1こ すくないだけ！ あと1こで 10**」を追加し、足りないマスを点線で光らせる（きりのいい数からの引き算でも見えるように）
- 数えるのが間に合わないときは「もういちど みる」で2回まで見直せる
- からのマスもうっすら表示。5と5の境目に破線を入れて2段構造を見せる
- 出る数は **5〜10が約95%**（上の段が5でうまって、下の段があといくつ、の練習）。1〜4は約20問に1問のごくまれ
- そのうえで苦手優先出題が効くので、間違えた数・時間がかかった数がよく出る
- じかんあり: ブロックを見ているあいだタイマーは止まり、隠れてから動きだす
- 初期はミッションのみカウント（20問）。設定でポケモン・コインゲージにも入れられる

設定タブで「表示時間（0.2〜10秒）」「最大の数（3〜10）」を変更できる。
初期値は1.5秒。うまくいかないときは3秒くらいに伸ばし、慣れたら短くしていくと数えグセが抜けやすい。
10個が多すぎるときは「最大の数」を6や7に下げる。

## ゲームじかんやさん

問題を解いて貯めたさいふのおかねを、ゲーム時間に交換するタブ。

- **500円 = 1時間**。購入ボタン1回で、さいふから500円を引いてゲーム時間を60分増やす
- ゲーム時間を使い終わったら「1時間つかった」を押し、確認後に購入済み時間を60分減らす。1時間未満ならボタンは使用できない
- 購入に成功すると、レジの「じゃららん」からベルの「チーン」へ続く音とチケット演出が出る
- 購入済みゲーム時間は端末に保存し、画面上部の中央（旧MAXコンボ欄）にも表示する
- さいふが500円未満なら、不足額を表示して購入しない
- 廃止前の「とうし」に残っていた現在価値と旧ぎんこう残高は、更新後の初回起動時に一度だけさいふへ戻す

### データの持ち方

- さいふは `riku10v2-wallet-yen`（円）。旧 `riku10v2-coins`（100円が何枚か）からは自動で ×100 して引き継ぐ
- 購入済みゲーム時間は `riku10v2-game-time-minutes`（分）
- 旧とうしの返金済みフラグは `riku10v2-finance-refunded`

## 演出

- 正解で紙吹雪＋ほめことば6種ランダム＋コンボ表示（🔥Nれんぞく）
- 正解音はアルペジオ。コンボ5ごとに1音ずつ豪華に（最大7音）
- もぎダンジョンは左右の間隔を広げ、ブロック1つ1つの枠を左＝黒・右＝白に分けて「別のあつまり」に見せている（移動すると枠の色も引っこし先に変わる。中の色は生まれたがわのまま）
- ひきざんジムは任意のブロックをタップして消せる。必要数を消すと答えカードが出る。ブロック表示は設定でほかのモードと別に切り替えられる

## 注意

- ポケモン画像はPokéAPI（公式アートワーク）から取得。初回はオンライン必須、以降はキャッシュ
- ポケモンは任天堂の著作物のため**ネット公開・配布はしないこと**（家庭内利用のみ）

## 試し方

`index.html` をブラウザで開く。PWAはObsidianSyncルートで:

```sh
python3 -m http.server 8097
```

→ `http://localhost:8097/Projects/riku-10-land/index.html`

iPhoneは同じWi-FiでMacのIPを使い、Safari共有→「ホーム画面に追加」（モンスターボールのアイコンになる）。
